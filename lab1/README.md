# Лабораторная № 1, вариант 6

Две программы на C. В каждой строке файла — целые числа типа `int`, разделённые
пробелами. Ребёнок считает сумму каждой строки, родитель выводит результаты.

Запуск на Linux или macOS **из папки `lab1`**:

```sh
cd lab1
make
./parent
```

Введите `input.txt`. Результат:

```text
6
-3
0
23
-1
```
